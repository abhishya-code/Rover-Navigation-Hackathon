## 📌 Project Overview
Planetary rovers exploring unstructured lunar or Martian environments require robust, autonomous navigation capabilities to operate safely without real-time human intervention[cite: 2]. Our project focuses on developing foundational intelligent algorithms and conceptual designs to tackle autonomous pathfinding and obstacle management.

---

## 🛠️ Key Features & Implementation
* **Obstacle Detection:** Basic logic designed to identify surface barriers in unstructured terrain.
* **A\* Path Planning:** Implemented the $A^*$ search algorithm to compute optimal, collision-free paths.
* **Conceptual CAD Model:** A preliminary 3D CAD design modeled to visualize the rover's structure.

## 📦 Libraries & Dependencies
To run this project, make sure you have the following libraries installed:

* **Python 3.x** (Recommended version)
* `numpy` — For matrix operations and grid handling
* `matplotlib` — For visualizing the $A^*$ path planning grid and obstacle mapping
* `opencv-python` — For image-based processing or visualization
